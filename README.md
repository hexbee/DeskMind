# DeskMind

![publish](https://github.com/hexbee/DeskMind/actions/workflows/release.yml/badge.svg?branch=stable)

An open-source desktop AI chat client built with Tauri (Rust backend) and React.js (frontend), supporting Model Context Protocol (MCP) for advanced conversational AI.

## Usage

- Enter the API key when asked.
- Start chatting!

## Development

- Clone the repository.
- Make sure you have rust installed.
- Run `pnpm install` to install the dependencies.
- Run `pnpm tauri dev` to start the app.
